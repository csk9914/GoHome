# GoHome 리스크 · 미결정 사항 통합 체크리스트

> 기반 문서: [기획서](01_GoHome_기획서.md) · [기술 분석서](02_GoHome_기술분석서.md) · 관련 문서: 착수 로드맵(Notion) · [참고문서 교차매핑](05_GoHome_참고문서_교차매핑.md)

이 문서는 세 역할만 한다: **⓪ 미션 가이드 필수 요건 대조**(아래 0번, 최우선 검토 필요), **① 진짜 남은 미결정 항목**(아래 1번), **② 이미 끝난 결정들의 색인**(아래 2번, 상세 내용과 근거는 각 결정이 실제로 적힌 01/02 문서에 있고 여기는 링크만 제공). 표에 나온 수치(소음 반경, 아이템 무게/가치, 도킹 문 트리거 조건, FPS 목표 등)는 모두 **플레이테스트 전 초기 작업값**이며 조정될 수 있다.

## 0. ⚠️ 미션 가이드라인 대조 — 필수 요건 충족 여부 (최우선 검토 필요)

`프로젝트 미션 가이드.docx` 대조 결과 필수 요건 중 4가지가 1차 범위에 없었다. 전부 처리 방향 확정: **플레이어 상호 방해**만 1차, **환경 방해 요소 2종**·**2인 협동 장치**·**목표 점수 시스템**은 2차 배정.

| 상태 | 미션 가이드 필수 요건 | GoHome 현재 상태 | 심각도 |
|---|---|---|---|
| ☑ | 2인이 협력해야 하는 물품 또는 장치 | 2차 추가 확정 — 동시 트리거 게이트. [01문서 7-1절](01_GoHome_기획서.md#7-1-2인-협동-장치) | 🟢 해결(2차) |
| ☑ | 제한 시간 안에 목표 점수 달성 | 2차 추가 확정 — 목표 점수(할당량) 시스템. [01문서 7-2절](01_GoHome_기획서.md#7-2-목표-점수할당량-시스템) | 🟢 해결(2차) |
| ☑ | 환경 방해 요소 2종 이상 | 1차는 도킹 문(1종)뿐. 2번째(수류 구간)는 2차로 이동 확정(기획 수정). [01문서 7-3절](01_GoHome_기획서.md#7-3-환경-방해-요소-2번째-종류-수류-구간) | 🟢 해결(2차) |
| ☑ | 플레이어 실수로 다른 플레이어 운반 방해 | 신규 시스템 없이 1차 포함 — 캐릭터 충돌 + 도킹 문 개폐. [01문서 3-7절](01_GoHome_기획서.md#7-플레이어-간-상호-방해--신규-시스템-없이-1차에-포함-검증-추가-팀-결정) | 🟢 해결(1차) |
| ☑ | 운반 물품 3종 이상 | 충족 — 일반형/파손형/소음 유발형 | ✅ |
| ☑ | 2~4인 협동, Listen Server | 충족 | ✅ |
| ◐ | 위험과 보상 구조 | 1차는 소음 유발형 아이템으로 부분 충족, 2차 목표 점수로 강화 | 🟡 중간 |
| ☑ | 성공/실패/재도전 흐름 | 충족 | ✅ |

> ⚠️ **남은 리스크**: 아래 1번 표 "1차 프로토타입만 별도로 제출/평가되는 마일스톤이 있는지 확인" 항목 참고.

> **표기 원칙**: 1차/2차 배정은 위 표 심각도 칸의 "해결(1차)"/"해결(2차)"가 유일한 표기이며 다른 곳에 중복 기재하지 않는다. 배정 근거는 [01문서](01_GoHome_기획서.md) 각 항목([7-1](01_GoHome_기획서.md#7-1-2인-협동-장치)/[7-2](01_GoHome_기획서.md#7-2-목표-점수할당량-시스템)/[7-3](01_GoHome_기획서.md#7-3-환경-방해-요소-2번째-종류-수류-구간))에 있다.

**참고**: [팀원2안·팀원3안·팀원4안](05_GoHome_참고문서_교차매핑.md#팀원-원안-요약) 모두 2인 협동 장치와 목표 점수 시스템을 코어 요소로 포함하고 있었다.

## 2. 결정 완료 색인

> 상세 내용·수치·근거는 모두 링크된 절에 있다. 여기서는 "무엇이 결정됐는지"만 항목별로 찾는다. 각 항목은 독립된 소제목이라 다른 문서에서 특정 결정 하나만 앵커로 링크할 수 있다. 시점 추적은 git log/blame으로 한다(표기 관례상 날짜는 여기 적지 않는다).
