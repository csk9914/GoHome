# GoHome

심해판 리썰 컴퍼니(Lethal Company-like) 협동 서바이벌 게임. 2–4인 협동으로 잠수정을 타고 침수된 심해 시설에 들어가 물자를 회수하고, 살아서 돌아와 정산하는 루프를 반복한다.

- 엔진: Unreal Engine 5.7
- 타겟 플랫폼: PC(Windows) / Steam
